# fouadsfarah.com

Source for [fouadsfarah.com](https://fouadsfarah.com), Fouad Farah's personal website: a single static page built with Astro, TypeScript and vanilla CSS, served by a Cloudflare Worker with static assets.

```sh
npm install
npm run dev     # local preview
npm run build   # static build into dist/
```
